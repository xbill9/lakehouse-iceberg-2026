# Sandbox, measured the same day, codex only
#
# `codex exec` runs its own shell tool under sandbox: read-only with no network

# nothing about MCP under the codex sandbox should be claimed yet.

# Server registration is global state on codex, and it is not empty
#
# `codex mcp list` during a prepared run showed the harness's server alongside
# `developer-knowledge`, an unrelated server installed globally by a plugin.
# claude is launched with --strict-mcp-config and sees only the cell's server;
# codex and agy have no equivalent, so their cells carry an extra tool surface
# the claude cells do not. This is a confound on axes A and B and has to be
# handled -- not merely noted -- before the matrix is run.

# Axis C is not available, measured 2026-09-16
#
# Axis C exists to pin one model across the hosts, so a host difference is not
# also a model difference. It cannot be done here, in either direction:
#
#   $ claude --model gemini-3.8-flash-medium -p "say ok"
#   "gemini-3.8-flash-medium" isn't described by this version's model catalog
#   There's an issue with the selected model ... It may not exist or you may not
#   have access to it.
#
#   $ agy --print "say ok" --model claude-opus-5
#   error: invalid model selection: model claude-opus-5 is not recognized as a
#   known model or custom model in settings
#
# Paper 3 removed this confound by running Strands on Gemini beside ADK on
# Gemini: an agent framework is a library, and you hand it whichever model you
# like. A CLI coding agent is not a library, it is a product bound to its
# vendor's models, so the same move is unavailable. Every host difference
# measured here is a host-and-model difference, and there is no later analysis
# that separates them.
#
# That is the honest shape of the result, and it is worth stating plainly rather
# than approximating: for this class of tool, "which is better" and "whose model
# is better" are the same question.
