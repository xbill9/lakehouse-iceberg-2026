# question: How many namespaces are in this catalog, and what are they called?

**One namespace, `probe_ns`** — with the caveat below.

The `ours-rows` server has no `listNamespaces` tool; the only catalog listing it exposes is `iceberg_list_tables`, which returned:

```
probe_ns.probe_large
probe_ns.probe_table
```

Deduplicating those prefixes in the shell gives exactly one distinct namespace, `probe_ns`. So what's measured is "namespaces that contain at least one table", not "namespaces in the catalog" — an empty namespace, or one holding only views, would be invisible to this tool. If you need the true count, that has to come from a `GET /v1/namespaces` call against the REST catalog rather than from these three tools.
