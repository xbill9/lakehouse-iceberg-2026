# question: How many namespaces are in this catalog, and what are they called?

**One namespace: `probe_ns`.**

`iceberg_list_tables` with no namespace argument (it lists every namespace) returned exactly two lines:

```
probe_ns.probe_large
probe_ns.probe_table
```

Stripping the table component and deduplicating gives 1 distinct namespace, `probe_ns` — the count and the dedupe were done with `sed | sort -u | wc -l` over that output, not read off by eye.

One caveat about what this does and does not measure: the server exposes no list-namespaces tool, so this is the set of namespaces that *contain tables*. An empty namespace, or a parent level of a nested namespace, would not appear in a table listing at all. If you need the catalog's actual `GET /v1/namespaces` answer, that has to come from the REST catalog directly rather than through these four tools.
