LaunchDarkly, "Benchmark LangGraph, Strands, OpenAI Agents, and Google ADK on the same agent graph", 2026-06-09
  https://launchdarkly.com/docs/tutorials/agent-graph-experiments
  frameworks: LangGraph, Strands, OpenAI Agents SDK, Google ADK; model pinned to claude-sonnet-4-5
  measured: graph latency, tokens, LLM-as-judge quality; 36 runs (six runs over six topics)
  task: agents analysing arXiv papers through a fetch_paper tool
  result: "Strands won on speed"; differences "often within a few percent"

Ma, Shankar, Chen, Lin, Zeighami, Ghosh, Gupta, Gupta, Gopal, Parameswaran,
"Can AI Agents Answer Your Data Questions? A Benchmark for Data Agents", arXiv:2603.20576, 2026-03-21
  https://arxiv.org/abs/2603.20576
  54 queries across 12 datasets, 9 domains and 4 database management systems
  five frontier models; best 38% pass@1

FDABench: A Benchmark for Data Agents on Analytical Queries over Heterogeneous Data, arXiv:2509.02473
  https://arxiv.org/abs/2509.02473
KramaBench: a benchmark for AI systems on data-to-insight pipelines over data lakes, arXiv:2506.06541
  https://arxiv.org/abs/2506.06541

Bian, Yan, Jayarajan, Pekhimenko, Venkataraman, "What Limits Agentic Systems Efficiency?", arXiv:2510.16276, 2025-10-18
  https://arxiv.org/abs/2510.16276
  "web environment latency can contribute as much as 53.7% to the overall latency in a web-based agentic system"

AWS Labs, S3 Tables MCP server
  https://github.com/awslabs/mcp/tree/main/src/s3-tables-mcp-server

  no latency or correctness evaluation published on the page
