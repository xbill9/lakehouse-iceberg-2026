Background for a LinkedIn post about "Four Iceberg Tools, Three Agent Frameworks".
Plain text on purpose: LinkedIn renders no markdown. Figures are from
evidence/matrix-summary.txt and evidence/derived-figures.txt, measured 2026-09-15,
ten runs per cell, 180 timed runs.


THE SETUP

Companies keep big tables of data in a standard format called Apache Iceberg, so
that any tool on any cloud can read the same data.

Each big cloud (Google, Amazon, Microsoft) also sells its own toolkit for building
AI agents: helpers that go and look things up for you.


THE QUESTION

If I build an AI helper that answers questions about my data with Google's toolkit,
can I move it to Amazon or Microsoft without starting over?


WHAT I BUILT

One small AI helper with four tools: list the tables, describe one, count its rows,
read its rows. Then I built it three times -- Google ADK, AWS Strands, Microsoft
Agent Framework -- with the same tools and instructions. Only the toolkit and the AI
model underneath change.

Every answer is checked against the real data, with no AI involved, and every
answer has to name the exact version of the table it read.


WHAT I FOUND

- The code that builds the helper barely changes. Running it does: calling it,
  signing in and reading its answer are different jobs in each toolkit.
- Speed follows the AI model, and mostly how much it writes. The slowest helper
  took about 4x as long as the fastest, but it also wrote about 3x as much text.
- The toolkit can matter too, but not consistently: on one question Strands was
  about 40% slower than Google's toolkit running the same model; on another they
  were level.
- The real per-cloud work is the plumbing that opens the data files. Each cloud
  needs different settings, and when they are wrong the error message points
  somewhere else.
- Once that plumbing is set up, every helper read its cloud's data, and every helper
  answered every data question correctly in all ten tries -- once the counting was
  done by the data engine rather than the AI. Left to count the rows itself, the
  smallest model, Amazon's Nova Micro, was right in 3 of 10 tries.
- Read the whole answer. One toolkit hands back only the last message by default,
  and one model writes part of its answer earlier in the conversation.


WHY SO CAREFUL

Articles that compare cloud companies get picked apart. So every number is produced
by a script from saved results, each test changes one thing at a time, every answer
is checked against the data itself, and anyone can re-run the whole thing from the
repo.
