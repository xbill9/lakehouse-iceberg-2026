I wanted to know whether an agent built on one cloud's framework actually moves to another, or whether you start over. So I built the same small read-only Apache Iceberg agent three times - Google ADK, AWS Strands, Microsoft Agent Framework - over the same four tools, and ran 360 timed runs against five catalogs.

The four tools ported unchanged. The code around them did not: calling the agent, signing in and reading its answer are three different jobs in each framework. The real per-cloud work turned out to be the storage wiring underneath the tools, not anything in the agent.
