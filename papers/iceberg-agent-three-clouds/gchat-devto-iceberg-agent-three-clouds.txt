This article is a step by step build of one small Apache Iceberg data agent, written three times: in Google ADK, in AWS Strands and in Microsoft Agent Framework. Each version runs against five Iceberg catalogs.

Every answer is checked against the catalog itself, so the differences between the three agents are measured rather than described.
